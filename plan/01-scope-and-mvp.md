# 01. Phạm Vi Sản Phẩm Và MVP

## Mục tiêu
Xác định phạm vi MVP đủ nhỏ để triển khai nhanh nhưng vẫn phản ánh đúng nghiệp vụ cốt lõi của eBuildFlow Pro.

## Phạm vi chức năng MVP
- [ ] Danh mục vật tư/hàng hóa
- [ ] Nhập kho
- [ ] Xuất kho / bán hàng
- [ ] Theo dõi tồn kho
- [ ] Khách hàng
- [ ] Nhà cung cấp
- [ ] Công nợ phải thu / phải trả
- [ ] Thu chi
- [ ] Dashboard tổng quan
- [ ] Báo cáo cơ bản
- [ ] Phân quyền người dùng
- [ ] Nhật ký hoạt động
- [ ] Sao lưu / phục hồi dữ liệu ở mức tối thiểu

## Ngoài phạm vi MVP
- [ ] Tích hợp hóa đơn điện tử
- [ ] Đồng bộ thiết bị POS / máy in mã vạch
- [ ] Ứng dụng mobile native
- [ ] Tích hợp thanh toán bên thứ ba
- [ ] Tối ưu đa chi nhánh phức tạp

## User journey tối thiểu
1. [ ] Đăng nhập hệ thống
2. [ ] Tạo danh mục vật tư
3. [ ] Tạo nhà cung cấp và khách hàng
4. [ ] Nhập hàng vào kho
5. [ ] Bán hàng và trừ tồn
6. [ ] Ghi nhận thanh toán / công nợ
7. [ ] Xem dashboard và báo cáo

## Kết quả đầu ra
- [ ] Danh sách yêu cầu MVP chốt được
- [ ] Có tiêu chí rõ ràng để không mở rộng ngoài phạm vi
- [ ] Có luồng nghiệp vụ mẫu để thiết kế database và UI
