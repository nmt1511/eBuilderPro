# 05. Nền Móng Dự Án Và Chạy Lần Đầu

## Mục tiêu
Đảm bảo project có thể clone về, cấu hình và chạy được ngay lần đầu.

## Việc cần làm
- [ ] Dọn template mặc định không cần thiết
- [ ] Chốt cấu hình appsettings cho dev
- [ ] Thêm cấu hình EF Core
- [ ] Tạo DbContext
- [ ] Tạo migration đầu tiên
- [ ] Seed dữ liệu ban đầu
- [ ] Kiểm tra `dotnet build`
- [ ] Kiểm tra `dotnet run`

## Hạ tầng code tối thiểu
- [ ] Cấu trúc thư mục rõ ràng
- [ ] Extension methods cho service registration
- [ ] Error handling cơ bản
- [ ] Logging mặc định
- [ ] Layout và menu điều hướng ban đầu

## Tiêu chí “chạy một lần”
- [ ] Không lỗi thiếu connection string
- [ ] Không lỗi migration
- [ ] Trang chủ hiển thị được dashboard/landing
- [ ] Có dữ liệu mẫu để nhìn thấy luồng chính

## Kết quả đầu ra
- [ ] Project bootstrapped thành công
- [ ] Có đường chạy sạch từ local environment đến app
