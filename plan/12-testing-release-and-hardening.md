# 12. Kiểm Thử, Release Và Hardening

## Mục tiêu
Đảm bảo bản MVP đủ ổn định để bàn giao và mở rộng.

## Kiểm thử
- [ ] Smoke test
- [ ] Test luồng mua hàng
- [ ] Test luồng bán hàng
- [ ] Test cập nhật tồn kho
- [ ] Test công nợ
- [ ] Test phân quyền
- [ ] Test backup/restore

## Hardening
- [ ] Kiểm tra null reference
- [ ] Kiểm tra validate đầu vào
- [ ] Kiểm tra concurrency cơ bản
- [ ] Kiểm tra hiệu năng mức tối thiểu

## Release
- [ ] Chuẩn bị cấu hình production
- [ ] Kiểm tra build release
- [ ] Chốt checklist bàn giao

## Kết quả đầu ra
- [ ] MVP sẵn sàng phát hành nội bộ
- [ ] Có checklist để không bỏ sót bước quan trọng
